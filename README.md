# Hospital Management System

## Overview

The Hospital Management System is a Java-based application developed to simplify and automate hospital operations. It enables efficient management of patient records, doctor information, appointments, billing, and medical history through a user-friendly interface connected to a MySQL database.

---

## Features

* Patient Registration and Management
* Doctor Information Management
* Appointment Scheduling
* Medical Record Management
* Billing and Payment Management
* Search and Update Patient Details
* Secure Database Storage

## Installation

### 1. Clone the Repository

```bash
git clone https://github.com/Haresh2710/Hospital-Management-System.git
```

### 2. Open the Project

Import the project into your preferred Java IDE (Eclipse, IntelliJ IDEA, or NetBeans).

### 3. Configure the Database

* Install MySQL.
* Create a new database.
* Import the provided SQL file.
* Update the database username and password in the JDBC configuration.

### 4. Run the Application

Execute the `Main.java` file to start the application.
